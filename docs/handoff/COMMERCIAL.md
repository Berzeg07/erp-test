# COMMERCIAL

Take-home AthenAI: локальный Safe Revenue Loop на синтетике.

## Часы

| | |
| --- | --- |
| Разработка (срезы BOOT-0 … DOCS-1) | **6 часов** |
| Рекомендация письма | 10–16 часов, окно 48 часов после старта |

Ориентир по срезам (сумма = 6 ч): каркас и tenant; фикстуры / импорт / дедуп; policy + rules + mock LLM; draft / outbox / replies / CRM; метрики + админка + матрица 18 тестов; документы сдачи.

## Расходы

| Статья | Сумма |
| ------ | ----- |
| Живой LLM / токены провайдера | 0 (mock в процессе) |
| SMTP, внешняя CRM, scraping | 0 |
| Облако | 0 (Docker Postgres локально) |
| **Итого денег** | **0** |

## Три компромисса

1. **Нет живой модели.** LLM-adapter — детерминированный mock со строгой JSON-схемой, бюджетом фейковых токенов и kill-switch. Нет ключей в `.env` по умолчанию.
2. **Один сервис и одна панель оператора.** Нет публичного кабинета «для клиента» и нет отдельного фонового процесса под очередь. Повтор доставки в CRM и DLQ крутит тот же API, факты лежат в Postgres.
3. **Один канал и тонкий UI.** Только `mock_email`; CTA из политики. Human minutes — константы (2 за approve, 5 за review), не трекинг мыши. Админка нужна, чтобы немое видео читалось без Swagger; оценка HR по письму — API.

Следствия, которые из этого следуют и тоже не делались: SMTP, роли user/moderator, снятие opt-out автоматом, склейка фирм только по имени.
